Project Overview
🕊️ Mission

Angaza (Swahili: to illuminate) is a spiritually grounded AI voice assistant built for Kenyan churches. It helps congregants engage with scripture, manage prayer requests, access church events, and grow spiritually — all through natural voice interaction in English and Swahili.

⚡ Core Capabilities
  • 📖 Emotion-aware scripture retrieval (RAG)
  • 🎙️ Voice-first (Whisper ASR + Neural TTS)
  • 🙏 Prayer request recording & routing
  • 📅 Church event scheduling integration
  • 💸 Voice-guided digital giving
  • 🇰🇪 English + Swahili bilingual support
🛡️ Safety & Ethics Framework
✅ ALWAYS
Ground answers in scripture • Remain warm and gentle • Respect all denominations • Support in both languages
🚫 NEVER
Political debates • Inter-church disputes • Complex pastoral counseling • Controversial theological doctrines
🔄 REDIRECT
Deep pastoral needs → "Consult your Pastor" • Medical concerns → Professionals • Legal issues → Qualified advisors

Development Roadmap — 4 Phases
Phase 1 — MVP: Voice Core
Get a working voice-in, scripture-out pipeline running locally
Weeks 1–3
  • Set up FastAPI project structure with CORS and health endpoint
  • Integrate Groq Whisper API for speech-to-text transcription
  • Build FAISS vector index with initial 100 scripture seed data
  • Implement emotion detection using Groq LLaMA3
  • Create core RAG function: emotion → FAISS search → verse retrieval
  • Integrate Edge TTS (sw-KE-ZuriNeural for Swahili, AriaNeural for English)
  • Simple React frontend with mic button and verse display
  • Deploy to Railway or Render (free tier)
Phase 2 — Scripture Integration
Full Bible ingestion, multi-version support, and theological Q&A
Weeks 4–6
  • Ingest full KJV, NIV, ESV via Bible API or local XML files (31,102 verses each)
  • Build FAISS index for all verses with metadata (book, chapter, testament)
  • Add denominational doctrine document ingestion (church-uploaded PDFs)
  • Implement daily devotional generation based on church calendar
  • Add memory: store user's verse history to avoid repetition (Redis)
  • Theological Q&A with RAG context retrieval
  • Swahili Bible data integration (Kiswahili Bible — free open source)
  • Testing: 50+ conversation scenarios across emotions and languages
Phase 3 — Church Operations
Admin integrations, prayer routing, giving, and pastor dashboard
Weeks 7–10
  • Church Management System API: events, announcements, service schedule
  • Google Calendar integration for real-time event queries
  • Prayer request system: record, categorize, and route to pastor (email/WhatsApp)
  • Voice-guided digital giving with M-Pesa integration (Kenya market)
  • Pastor admin dashboard: view prayer requests, user insights, popular verses
  • Multi-church support: church_id scoping for all queries
  • Sermon Q&A: ingest sermon transcripts, allow post-service questions
  • User auth: phone number OTP (common in Kenya, no email required)
Phase 4 — Final Polish & Scale
Production hardening, offline support, and community features
Weeks 11–14
  • PWA: offline mode with cached scriptures for low-connectivity areas
  • WhatsApp bot integration (most widely used in Kenya)
  • USSD fallback interface (*123#) for feature phone users
  • Spiritual growth tracking: streak, verse history, answered prayer log
  • Personalized devotional plans (7-day, 21-day, topical)
  • Load testing and rate limit optimization for Groq free tier
  • Security audit: input sanitization, auth hardening
  • Beta launch with 3 pilot churches in Nairobi

# Angaza Core RAG Function — Free Stack # HuggingFace Embeddings + FAISS + Groq LLaMA3 from sentence_transformers import SentenceTransformer import faiss, numpy as np from groq import Groq # Emotion → theological topic mapping EMOTION_TOPICS = { "anxious": ["peace", "trust in God", "do not worry"], "grieving": ["comfort", "God heals the brokenhearted"], "fearful": ["courage", "God is with you"], "hopeless": ["hope in Christ", "resurrection"], } class AngazaRAGEngine: def __init__(self, groq_key: str): # Free HuggingFace model — 384-dim embeddings self.embedder = SentenceTransformer( "sentence-transformers/all-MiniLM-L6-v2" ) self.llm = Groq(api_key=groq_key) self._build_index() def retrieve_scripture(self, emotion: str, query: str): # Build enriched semantic query topics = EMOTION_TOPICS.get(emotion, ["God's love"]) enriched = f"Bible verse about {topics[0]} for someone feeling {emotion}" # FAISS semantic search vec = self.embedder.encode([enriched]) distances, idx = self.index.search( np.array(vec, dtype="float32"), k=3 ) best = self.scriptures[idx[0][0]] # Generate devotional note via Groq (free tier) note = self.llm.chat.completions.create( model="llama3-8b-8192", messages=[{"role": "user", "content": f"Write a 2-sentence warm devotional for someone feeling {emotion} based on: {best['text']}"}], max_tokens=100 ) return { "reference": best["reference"], "text": best["text"], "devotional": note.choices[0].message.content }
# Emotion Detection via Groq LLaMA3 (free tier) # Falls back to keyword matching for speed EMOTION_KEYWORDS = { "anxious": ["anxious", "worried", "stress", "nervous", "wasiwasi"], "grieving": ["sad", "grief", "lost", "died", "huzuni"], "fearful": ["afraid", "scared", "fear", "woga"], "hopeless": ["hopeless", "give up", "no point", "kukata tamaa"], "joyful": ["happy", "joyful", "blessed", "furaha"], "grateful": ["thankful", "grateful", "shukrani"], } def detect_emotion_fast(text: str) -> str: """Keyword-based fast path (no API call needed).""" text_lower = text.lower() for emotion, keywords in EMOTION_KEYWORDS.items(): if any(kw in text_lower for kw in keywords): return emotion return "seeking" # default def detect_emotion_llm(text: str, client: Groq) -> str: """LLM-based emotion detection for nuanced inputs.""" emotions = list(EMOTION_KEYWORDS.keys()) resp = client.chat.completions.create( model="llama3-8b-8192", messages=[{"role": "user", "content": f"Classify emotion in ONE word from {emotions}: '{text}'"}], max_tokens=5, temperature=0.1 ) result = resp.choices[0].message.content.strip().lower() return result if result in emotions else "seeking" def detect_emotion(text: str, client=None) -> str: """Smart routing: fast path first, LLM as fallback.""" fast = detect_emotion_fast(text) if fast != "seeking" or not client: return fast return detect_emotion_llm(text, client)
# Angaza Voice Pipeline # ASR: Groq Whisper (free) | TTS: Edge TTS (free, Swahili KE voice) import edge_tts, io from groq import Groq # Voice profiles — warm, reverent VOICE_PROFILES = { "en": "en-US-AriaNeural", # Warm US English female "sw": "sw-KE-ZuriNeural", # Swahili Kenya female ✓ "en_male": "en-US-GuyNeural", # Warm US English male } async def synthesize(text: str, lang: str = "en") -> bytes: """Convert text to reverent speech audio (MP3 bytes).""" voice = VOICE_PROFILES.get(lang, VOICE_PROFILES["en"]) # Slightly slower rate = more reverent delivery comm = edge_tts.Communicate(text, voice=voice, rate="-8%") buf = io.BytesIO() async for chunk in comm.stream(): if chunk["type"] == "audio": buf.write(chunk["data"]) return buf.getvalue() def transcribe(audio_path: str, lang: str = "en") -> str: """Transcribe audio using Groq Whisper (14,400 free req/day).""" client = Groq() with open(audio_path, "rb") as f: result = client.audio.transcriptions.create( model="whisper-large-v3", file=f, language=lang, # "sw" for Swahili response_format="text" ) return result.strip()
# FastAPI Endpoint — Emotion-Aware Scripture # POST /scripture/by-emotion from fastapi import FastAPI from pydantic import BaseModel class QueryRequest(BaseModel): user_id: str text: str # "I feel so anxious today" language: str = "en" # "en" | "sw" emotional_state: str = "" # Optional override app = FastAPI(title="Angaza API 🕊️") engine = AngazaRAGEngine(groq_key=GROQ_API_KEY) @app.post("/scripture/by-emotion") async def get_scripture(req: QueryRequest): # 1. Detect emotion emotion = req.emotional_state or detect_emotion(req.text) # 2. RAG retrieval result = engine.retrieve_scripture(emotion, req.text) # 3. Synthesize speech speech_text = f"{result['reference']}. {result['text']}. {result['devotional']}" audio_bytes = await synthesize(speech_text, lang=req.language) return { "reference": result["reference"], "text": result["text"], "devotional": result["devotional"], "emotion": emotion, "audio_b64": audio_to_base64(audio_bytes), "language": req.language }
